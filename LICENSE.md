## Suggested attribution string
> "<Dataset/Document title>" by Evidence for Resilient Agriculture (ERA),
> licensed under CC BY 4.0. Source: https://github.com/ERAgriculture/<repo>.
> <DOI if available>.

## How to apply in a repo
- For a **data** repo: add a `LICENSE` (or `DATA_LICENSE`) file containing this notice (and/or the full legal code), and state "Data: CC BY 4.0" in the README.
- For a **docs/website** repo: state "Documentation content: CC BY 4.0" in the README/footer.
- Always pair published datasets with a `CITATION.cff` and a DOI (see ADR-0004/0005).
